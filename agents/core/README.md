# AI Agents - Core Team

This directory defines the AI agents responsible for managing platform evolution.

## Agents

### 1. Architect Agent
- Defines structure and standards
- Reviews platform decisions

### 2. DevOps Agent
- Applies patterns (Docker, Cloud Run, Observability)
- Ensures runtime compatibility

### 3. Reviewer Agent
- Validates changes
- Checks best practices

### 4. Spec Agent
- Creates and maintains specifications (spec-kit)

---

## Objective

Create a self-improving system where agents:

- Review each other
- Improve documentation
- Maintain standards
- Suggest improvements

This system must be reusable for any service or platform.
