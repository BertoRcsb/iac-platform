# SDD Workflow

## 1) Research

Identify the minimal context: goals, constraints, relevant files, and reusable patterns.

## 2) PRD

Write a concise problem and scope statement with acceptance notes.

## 3) Spec

Define exact files to create/modify, per-file changes, and validation commands.

## 4) Code

Implement only the approved spec scope using existing standards.

## 5) Review

Verify diff correctness, run checks, and confirm documentation alignment.
