# AI Team - Continuous Learning

## Purpose
Maintain a collaborative AI team that continuously improves platform operations.

## Team Model
- Intake Agent captures and structures requests.
- Architect Agent defines approach and guardrails.
- Analysis Agent evaluates risk and evidence.
- Execution Agent applies controlled local actions.
- Review Agent validates output quality.
- Documentation Agent updates knowledge base.
- Notification Agent reports priorities and blockers.
- Release Agent controls promotion gates.
- Manager Agent (human) approves critical changes.

## Continuous Learning Contract
- Every executed task should generate learning output.
- Lessons must be recorded in `knowledge/lessons-learned.md`.
- Improvement proposals must be recorded in `knowledge/improvement-log.md`.
- Relevant operational decisions must be logged in `knowledge/decision-log.md`.
- Learning remains local-only unless explicitly approved for external integration.

## Objective
Create a self-updatable operational system where AI agents improve process quality over time with human governance.
