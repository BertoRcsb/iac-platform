# Agent Workflow

1. Task is received (from human)

2. Spec Agent:
   - Converts task into specification

3. Architect Agent:
   - Defines structure and approach

4. DevOps Agent:
   - Applies implementation

5. Reviewer Agent:
   - Validates changes

6. Documentation Agent:
   - Updates README and docs

---

## Goal

Create a continuous improvement loop:
AI reviewing AI → improving system quality
